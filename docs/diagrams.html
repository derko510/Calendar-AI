Calendar AI · system design

One message, one AI call

The chat no longer guesses with keywords or regex. Every message goes to /interpret, the model decides whether you want to create, delete, or ask, and the browser only touches Google Calendar after you confirm.

Architecture map

Fig. 1 · components and the chat path
Browser API route Service Database External Chat request path Fallback / faded = legacy
  1. 1You type a message in the chat.
  2. 2The chat sends it, with your synced events and time zone, to /interpret.
  3. 3The route builds one prompt and calls llm.generate in JSON mode.
  4. 4Groq returns intent + data. The route validates it and retries once if it is unusable.
  5. 5For create or delete, the chat shows a confirm card. Nothing changes until you click.
  6. 6The browser writes straight to Google Calendar with your OAuth token.
